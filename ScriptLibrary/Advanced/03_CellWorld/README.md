# Advanced 03_CellWorld

These retain the pre-simplification fluid rules, with shared polygon boundary support added. Use ../../Switch-Script-Edition.cmd to install this complete module. Keep its metadata; do not copy this folder into Assets.

Both CellWorld2D and CellWorldPoly2D work with the same tool, plants, lights, and optional swimming references. See Docs/POLYGON_CELLWORLD_GUIDE.md for setup and Docs/BEGINNER_CODE_GUIDE.md for edition differences.

Basic plants use a plain loop over plant data instead of a dirty queue. They retain baked pixel masks, five damage stages, water protection, tile transforms, shared stage tiles, healthy collision until complete burning, and disappearance. Collision/registration geometry stays explicit because it is needed for the existing plant artwork and rotated/scaled tiles. Both files are one component (partial); swap the complete Plants module. BurnablePlantTile remains the simplest place to change burn time, stages, or collision.

# Vine sheet setup validation — 2026-09-23

Unity version: 6000.6.0f1. Validated in an isolated copy of the current BURN_I project, including its current Level_0. The live project's packages and project settings were not changed.

## Authored assets

- Ten 64×16 source PNGs, each containing four 16×16 frames. PNG pixels remain unchanged.
- Forty sprite slice names updated to `<shape>_burn0` through `<shape>_burn3`. All forty original sprite IDs and ten texture GUIDs verified after Unity import.
- Ten BurnablePlantTile assets generated by the normal selection command. Every type has four distinct artwork sprites, five filled stage slots (last frame repeated), and a freshly baked healthy mask.
- A recognized Unity Tile Palette, `Assets/Game/Tiles/BurnablePlants/Burnable Vines.prefab`, containing all ten plant assets. The existing Plants palette remains unchanged.
- A test patch on Level_0's existing Burnable Plants Tilemap. The player's saved position is approximately (97.18, 23.50); the patch occupies world cell centers x=99.5–103.5, y=24.5–25.5. It uses the Ground layer and one non-trigger TilemapCollider2D.
- One editor usability fix: newly generated tile objects get their plant's name, improving their Inspector names and diagnostic messages.

## Checks passed

- Selecting all ten named sheets produces exactly ten plant types.
- Each mask passes the existing build-time missing/stale-mask check.
- All ten plants register in the actual Level_0 in Play mode; no missing-mask/out-of-bounds warning.
- In a controlled combustion check, every registered healthy fuel cell accepts ignition, including cells inside sprite collision.
- Each type displays the expected sprite texture/UVs at each damage stage. Slot 4 intentionally repeats frame 3.
- Healthy collision is retained at all four damage transitions.
- Every plant disappears when fully consumed; its collision and stationary fuel are removed.
- Imported sprite/mask validity remains intact after burning.

The first preview attempt read cell centers before enabling a newly created Tilemap, so the test ignited the wrong positions. Reading them after enable resolved the test setup issue. No runtime combustion code was changed.

This verifies the real plant assets and gameplay state in Unity Play mode. It is not a frame-rate benchmark or a claim that the flame overlay leaves all damage artwork visible. Extinguish a partly burned vine to inspect its remaining sprite.

## Current level tuning

The user's existing fire settings are preserved: Fire Spread Chance is **0**, Fire Spread Every Ticks is **3**, and Upward Spread Bonus is **0.15**. Horizontal/downward spread is therefore disabled; upward spread can still happen. For the slower spreading preview discussed in the guide, try **0.05**, **12**, and **0.02** respectively. These are global CellWorld settings, not per-plant values.

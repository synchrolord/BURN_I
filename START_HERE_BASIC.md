# Basic edition

Active game: `Assets/Game/Scenes/Levels/Level_0.unity`.

Read [the beginner code guide](Docs/BEGINNER_CODE_GUIDE.md). It explains every active script, the C# syntax, tuning, plants, and adding features.

Active scripts: `Assets/Game/Scripts`.

Original advanced scripts: `ScriptLibrary/Advanced`. Clean basic copies: `ScriptLibrary/Basic`. These folders are outside Assets and do not run.

To switch one module, save/close Unity and double-click `ScriptLibrary/Switch-Script-Edition.cmd`. Commit and test one module at a time. It backs up your current scripts before replacement.

The bigger campaign/infection/enemy additions remain in the separate `../BURN_I_Feature_Library/Stages` library. Follow their README dependency order when ready.
